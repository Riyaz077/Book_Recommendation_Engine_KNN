# Book Recommendation Engine using KNN

## Included
- `Book_Recommendation_Engine_KNN.ipynb`: complete Jupyter/Google Colab notebook.
- The notebook downloads the Book-Crossings dataset, filters low-activity users and books, builds a pivot matrix, trains a cosine-distance KNN model, and defines `get_recommends()`.

## Run
1. Open the notebook in Google Colab or VS Code.
2. Run all cells in order.
3. The dataset download requires an internet connection.
4. Run the official freeCodeCamp test cell before submitting.

The notebook includes basic output-shape checks. Exact challenge acceptance must be confirmed using the official freeCodeCamp tests.
